# Employee Management System

## Overview
A console-based Employee Management System built using Core Java and Maven. This project reinforces object-oriented programming, collections, validation, layered architecture, and CRUD operations.

## Technologies
- Java
- Maven
- Git and GitHub
- Java Collections Framework

## Planned Features
- Add and register employees
- View all employees
- Search employees
- Update employee details
- Delete employees
- Validate employee information
- Prevent duplicate employee IDs and email addresses
- Search, filter, and sort employee records
- Generate basic employee statistics

## Storage
Employee records will initially be stored in memory using `ArrayList`. Database integration can be introduced in a later version.

## Project Status
In development.

## Learning Goals
Practise Core Java concepts, object-oriented design, collections, exception handling, testing, and Git version control.
